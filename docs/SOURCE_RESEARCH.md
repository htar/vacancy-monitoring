# Дослідження джерел вакансій

Станом на 29 жовтня 2026 року рекомендована архітектура моніторингу має три шари: структуровані API/RSS, публічні job boards і Telegram-канали через MTProto. API/RSS є стабільним ядром, а Telegram додає нішеві українські, європейські та relocation-вакансії.

## Джерела, додані за замовчуванням

- Jobicy — міжнародні remote-вакансії через JSON API.
- Arbeitnow — вакансії Європи, Німеччини та UK через JSON API.
- Remote OK — міжнародні remote-вакансії через JSON.
- We Work Remotely — категорійний RSS.
- Greenhouse — вакансії окремих компаній через публічні job-board endpoints.

Кожне оголошення зберігає оригінальне посилання. Опитування джерел виконується паралельно; помилка одного джерела не зупиняє інші.

## Telegram: основний каталог

Українські канали:

- `@junior_dou_ua`, `@dou_qa`, `@frontend_dou`, `@devops_dou`;
- `@itexpert_vacancies`, `@casesjobs`, `@DesJobUa`, `@dna325`.

Європа, remote та relocation:

- `@relocateme`, `@jobs_abroad`, `@jobs_in_european_countries`, `@jobsineu`;
- `@remotejobs`, `@remotejobpositions`, `@talentservicejobs`.

Ці канали входять до стартового каталогу. Користувач може змінювати його командами `/tgchannel add @channel`, `/tgchannel remove @channel` і переглядати через `/tgchannels`.

## Канали для підключення за потреби

Країнові канали варто вмикати лише для відповідної країни або мови, оскільки вони часто містять агентські оголошення й більше дублів:

- Польща: `@JobsIn_Poland`;
- Німеччина: `@jobde`;
- Чехія: `@czech_info_rabota`;
- Велика Британія: `@rabota_london`;
- Балтія: `@amountbaltic`;
- Нідерланди: `@jobsinamsterdam`;
- Фінляндія: `@StartupJobsInFinland`;
- Швеція: `@swedishjobs`.

Публічні групи з користувацькими дописами не слід змішувати з каналами без окремого антиспам-фільтра. Для агентських каналів потрібні перевірка доменів, дедуплікація й попередження не сплачувати за працевлаштування.

## Технічні обмеження Telegram

Bot API не може читати історію довільних чужих каналів. Для цього використовується окрема користувацька MTProto-сесія (`TG_API_ID`, `TG_API_HASH`, `TG_SESSION`). Bot API залишається відповідальним за команди й доставку результатів. Без MTProto-сесії всі API/RSS-джерела продовжують працювати.

Колектор завантажує останні 50 повідомлень кожного каналу після запуску, слухає нові та відредаговані дописи й відсіює кандидатські пости на кшталт «Шукаю роботу», «Ищу работу» та «looking for job».

## Наступні кандидати

- Lever — curated per-company feeds.
- Remotive — лише після перевірки ліцензійних обмежень і частоти запитів.
- EURES — авторитетне офіційне джерело ЄС, але перед інтеграцією потрібен підтверджений стабільний API або дозвіл на використання.
- Dev Global Jobs — humanitarian/development roles; комерційне повторне поширення потребує окремої перевірки умов.

Якість кожного Telegram-джерела потрібно оцінювати за 7–14 днів: частка унікальних вакансій, дублів, битих посилань, невакансійних дописів і помилкових збігів.
